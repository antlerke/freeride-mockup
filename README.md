# FreeRide — макет редизайну

Статичний прототип нового сайту мотошколи freeride.kiev.ua.
Це **макет**, не готовий сайт: форми нічого не надсилають, фото — заглушки,
текст у квадратних дужках треба замінити реальними даними.

Відкрити: `index.html` — перелік усіх екранів.

## Що всередині

| Файл | Що це |
|---|---|
| `index.html` | Перелік екранів |
| `home.html` | Головна: анімована траєкторія, підбір курсу, ціни |
| `instructors.html` | Інструктори, перемикач 1–3 для демонстрації |
| `course.html` | Сторінка курсу на прикладі базового |
| `about.html` | Про школу (мотопарк + галерея + відгуки разом) |
| `contacts.html` | Контакти й форма заявки |
| `mobile.html` | Ті самі сторінки в рамці телефона |
| `system.html` | Палітра, типографіка, елементи, правила руху |
| `heroes.html` | Два альтернативні напрями першого екрана |
| `assets/site.css` | Усі стилі, токени й анімації |
| `assets/app.js` | Підбір курсу та перемикач кількості інструкторів |
| `assets/showcase.css` | Скрол-режисура іміджевої головної |
| `assets/showcase.js` | Прогрес секцій, лічильники, перемикання роликів |
| `assets/video/` | **Тимчасові** стокові ролики та їхні постери |

## Технічне

Чистий HTML + CSS + трохи JS, без збірки й залежностей. Шрифти — Google Fonts
(Unbounded для заголовків, Manrope для тексту). Весь рух має версію для
`prefers-reduced-motion`.

Сторінки закриті від пошукових систем через `robots.txt` і `noindex`.

## Відео — тимчасове

`assets/video/ex1–ex4.mp4` — кадри зі stock-бібліотеки [Coverr](https://coverr.co),
ліцензія дозволяє безкоштовне комерційне використання без згадки автора.
Це **заглушки**: у вільних бібліотеках немає зйомок навчального майданчика
(конуси, вісімка, габаритний розворот), тому кліпи показують звичайну їзду
й лише приблизно відповідають підписам. Замінити власною зйомкою.

Вихідні файли стиснуті: 8 с, без звуку, 960px по ширині, h264 crf 30 —
близько 300–470 КБ кожен. Постери згенеровані з першої секунди.

Герой головної поки без відео — там CSS-заглушка. Потрібна зйомка від першої
особи: 12–20 с петлею, без звуку, 1920×1080, до 4 МБ, плюс кадр-постер.
